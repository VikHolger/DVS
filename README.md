## Mål med vad verktyget kan göra
- Hjälper medlemar skriva verifikat
- Medlemar kan lägga up kvitton och skicka verifikatet & kvittot via enbart hemsidan
- Admins kan se alla ärenden, bara en viss post, bara mynt eller privata utlägg, se ärenden det hanterat eller måste hantera, och kunna sortera på ovanämnda saker
- Admins kan gå in på ett ärende, ladda ner dens verifikat och kvitto, samt ticka av när ärendet är hanterat
- Admins kan kontakta ärendeägaren enkelt för att begära mer info, eller ändring av verifikatet till ett korekt. Medlemar ska då kunna enkelt ändra i verifikatet utan att behöva skapa ett helt nytt ärende.
- Admins kan lägga olika flaggor på ärenden som det kan sortera ärenden på så det enklare kan få hjälp av andra admins.

## Potentiela mål som kommer undersöka om det går att genomföras efter huvudprodukten är levererad
- Hjälpa en att tolka snabbgross kvitto och hitta varos olika momsatser
- Undersöka om Fortnox, Snabgross o Mynt har API och om det går att användas till denna produkt
