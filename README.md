## Mål med vad verktyget kan göra
- Hjälper medlemar skriva verifikat
- Medlemar kan lägga up kvitton och skicka verifikatet & kvittot via enbart hemsidan

## Potentiela mål som kommer undersöka om det går att genomföras efter "lanseringen"
- Att DVS hjälper till att tolka snabbgross kvitto och hitta varos olika momsatser
